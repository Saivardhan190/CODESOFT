# Java Internship Tasks at CodeSoft
This repository contains a collection of tasks completed during my Java internship at CodeSoft. Each task showcases the application of core Java concepts and demonstrates problem-solving skills through practical implementations.

# About
The tasks span various real-world scenarios, from creating interactive console applications to developing logic-driven solutions. Below is a summary of each task:

## Task 1: Number Guessing Game
## Objective: 

Guess the correct number (between 0 and 99) within a limited number of attempts.

## Features:

1.User-friendly input/output interactions.

2.Scoring system based on attempts remaining.

3.Option to play again after each round.

4.Core Concepts Used: Loops, conditional statements, Scanner class, and basic game logic.

## Task 2: Grade Calculator
## Objective:
Calculate total marks, percentage, and grade based on user-inputted subject marks.

## Features:

1.Accepts the number of subjects and their respective marks.

2.Dynamically calculates grades based on the percentage.

3.Displays total marks, percentage, and grade classification.

4.Core Concepts Used: Arrays, loops, and conditional logic.

## Task 3: ATM Machine Simulation
## Objective: 
Simulate basic ATM functionality with options for withdrawal, deposit, and balance inquiry.

## Features:

1.Handles deposit and withdrawal transactions with real-time balance updates.

2.Displays error messages for invalid transactions (e.g., insufficient balance).

3.Offers a menu-driven interface with continuous operation until exit.

4.Core Concepts Used: Classes, methods, encapsulation, and switch-case statements.

## Task 4: Timed Quiz Application
## Objective: 
Conduct a timed quiz where users must answer multiple-choice questions within a specified time.

## Features:

1.Displays questions and multiple-choice options.

2.Timer-based answer submission (10 seconds per question).

3.Calculates and displays the user's score at the end of the quiz.

4.Core Concepts Used: Collections (ArrayList), multithreading (ScheduledExecutorService), exception handling, and I/O operations.

## Features
Each task highlights practical applications of Java programming concepts.

User-friendly console-based interactions.

Error handling to ensure smooth user experience.

Demonstrates foundational programming skills suitable for real-world scenarios.

## Prerequisites

Java Development Kit (JDK) installed.

Basic understanding of Java programming.
